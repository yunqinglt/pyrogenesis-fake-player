# 本版已知问题

核对日期：2026-11-06。本次分发未修改游戏／模组运行代码。

1. 己方观察枚举可能混入同所有者的历史影像（`mirage`），导致 `zy_mcp_properties.js:304` 报 `Unit properties require a normal player entity.`。已使用真实 JS 和合成对象离线重现。错误可能使普通观察暂不可用，网络仍连接时也会出现 `ready=false`。这是观察桥接缺陷；计划修复点是在 `ownStates` 属性查询前排除影像，同时保留正常驻军单位和模拟端严格校验。当前包尚未部署该修复。
2. 恢复部分残局加入联机时，曾出现 `mozjs128-release.dll+0x477c69` 访问违规。只撤回新集结点属性读取的对照仍崩溃，因此该新增读取不是必要条件。房主另报过 `Error loading js`，尚无证据证明这些异常同因；恢复存档的兼容性仍需逐例验证。
3. 安装自检只验证包数据、MCP 握手和空闲状态，不启动游戏。自检通过不能证明具体地图、文明、存档恢复或所有动作均已实战通过。三个策略技能的计划脚本和合成场景已验证，执行效果仍须以当前对局观察确认。

遇到上述问题应保留对应版本、时间和错误日志，避免用旧观察重复训练／建造。诊断日志用于定位软件异常；玩家决策仍只使用公开 MCP 观察。不要为排查而关闭用户的手动房主。
