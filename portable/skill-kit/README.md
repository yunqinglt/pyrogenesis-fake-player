# 0 A.D. 玩家策略与残局分析技能包

将 `skills/` 内需要的目录复制到模型客户端支持的技能发现目录，每个目录保留完整结构。Codex 的当前目录说明见另行提供的 player-kit 包 `CONFIGURATION.md`；支持直接读取文档的其他模型也可读取对应 `SKILL.md` 使用。

- `0ad-train-near-civic`：输入市政中心 ID、单位模板 ID 和本次追加数量，在同一基地附近的可用建筑中按距离与队列负载分配训练，含符合条件的市政中心。
- `0ad-build-resource-storehouse`：输入已知资源区域／目标，比较现有存放点、候选位置和建造者，再经地基与完工观察确认仓库建设。
- `0ad-rally-idle`：输入类别与目的坐标，筛选全部／公民兵／平民／骑兵／冠军中的真正空闲对象，每批最多 200 人集结。
- `0ad-analyze-save`：离线读取用户提供的 `.0adsave`，生成 JSON、中文报告与交互对象图，并比较残局中的经济、布局和策略倾向；完整标准库解析器随技能提供。

前三项技能需要已经连接的本项目普通玩家 MCP（24 个工具），动态信息只从公开工具取得；其中 `analyze_terrain_region` 可用于在线选址前的采样比较。残局分析技能独立运行，仅需 Python 3.11+、用户存档及同版本公开游戏模板，不启动游戏或 MCP。其报告为 `offline-save-omniscient`，不可回灌为公平实战中的玩家观察。技能包不包含服务器、游戏资源、真实存档或模型，也不自动配置客户端。完整游戏规则和模型玩家提示词在独立 player-kit 归档内。

训练与集结附带 Python 3.11+ 标准库计划脚本：读取 `{observation:公开observe_player结果, request:技能参数}`，输出工具调用计划。它们不启动服务、不接管会话、不执行游戏动作。没有终端能力的模型可按技能中的步骤直接调用公开 MCP 工具。执行前复核当前状态，提交后观察确认；计划不是完成证明。

可在包目录用 `python verify_bundle.py` 校验文件。独立技能目录内部不引用包外文件；无需复制本 README 或校验器到技能发现目录。
