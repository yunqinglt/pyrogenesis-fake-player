# 0 A.D. 模型玩家包

本包与 MCP server 包分离：本包提供玩家提示词、规则和策略技能，服务器包提供可安装的 stdio 服务及伴随模组。将两个 ZIP 分别解压，先按 server 包的执行说明完成安装／自检与客户端配置，再将 [ENTRYPOINT.md](ENTRYPOINT.md) 的入口提示交给模型。

玩家必读：[AGENT.md](AGENT.md)、[MCP.md](MCP.md)。可直接使用精简的 [玩家系统提示词](prompts/player-system.md) 和 [本局任务模板](prompts/task-template.md)，再按需读取详细文档。本包文件中的历史实体 ID、游戏时间和运行产物路径仅为验证记录；动态局势仍须从当前公开 MCP 观察取得。本包附带独立残局分析技能与解析器，供用户委派的离线复盘使用，不附带存档、全知局势数据或官方游戏模板。

四个技能位于 `skills/`：附近建筑批量训练、资源附近仓库选址、空闲单位集结和 [残局分析](skills/0ad-analyze-save/SKILL.md)。按所用模型客户端的技能发现目录安装，或直接读取对应 `SKILL.md`。配置和安装位置说明见 [CONFIGURATION.md](CONFIGURATION.md)。前三项的附属规划脚本仅处理已经取得的公开观察，不连接游戏，不启动第二个 MCP 服务，也不会自动提交动作。残局分析则读取用户指定的离线存档，不依赖 MCP；全知报告不能用于公平对战中的实时决策。

当前版本的观察桥接与存档恢复限制见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。安装自检与技能计划验证不替代实际游戏结果。

本包的 `AGENT.md` 是玩家手册，不能假定客户端会自动将其当作 `AGENTS.md` 注入。目录可以随包复制；入口提示应给出解压后的实际文档位置。

用任意 Python 3.11+ 执行 `python verify_bundle.py` 可检查随包文件清单。清单未签名，不能独立证明发布者身份。原始开发机的用户名和用户目录已在复制的说明文本中替换为通用示例；服务器不携带任何个人客户端配置。
